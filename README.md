# Halo-Halo Hacienda

`HaloHaloHacienda.rbxlx` is a compact, playable Roblox place for the Filipino cozy-cooperative farm game concept.

## Included

- Normal-sized barangay map with a plaza, river, ancestral home, kusina, shrine, and six player plots.
- Farming interaction: plant and harvest nine crop beds per plot.
- Karabao pet interaction for bonus Ngiti.
- Kusina cooking and spirit order interactions.
- Server-wide Bayanihan event every 15 seconds, with a 35-second community task and a three-helper success target.
- Automatic plot assignment for up to six active players.
- Client HUD for plot assignment, Ngiti, spirit orders, toasts, and the Bayanihan progress bar.

## Open and publish

1. Open `HaloHaloHacienda.rbxlx` in Roblox Studio.
2. Press **Play** to test the farm loop. Use **Start** with multiple players to test Bayanihan.
3. Set the experience name, thumbnail, and permissions in **Game Settings**.
4. Use **File > Publish to Roblox** to create or update the live experience.

The place is intentionally script-generated so the `.rbxlx` stays small and the map is easy to rebalance in one server script. Roblox Studio is still required for the final account-specific publish step.
